About these numbers

Performance readings refresh every 3 seconds; drives every 30 seconds. Cleanup and Apps show the last saved scan and never start one from this page.

Colour and a word always go together: under 70% is fine, 70–90% is busy, 90% and above is critical. Swap has no fixed limit, so it is shown as an amount without a bar.

Reclaimable is measured file size eligible to move to Trash, not promised free space.
